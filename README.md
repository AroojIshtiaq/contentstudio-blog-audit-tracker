# ContentStudio Blog Audit & Tracker

A prioritized blog management tool for ContentStudio's 1,040+ blog posts.

## Features
- SAV (Search Volume · Authority · Verified Traction) scoring framework
- Full search and filter by cluster, tier, action, year, owner, result
- Secondary GSC queries — collapsed by default, expandable per post
- Per-post tracking: owner (Saif / Arooj), revision date, changes made, results achieved, summary notes
- All tracking data saved in browser localStorage
- Export to CSV

## Live Site
https://aroojishtiaq.github.io/contentstudio-blog-audit-tracker/

## Usage
Open the live site. All edits (owner assignment, notes, dates, results) are saved locally in your browser.
Use the Export CSV button to download tracking data at any time.
